# AWS S3 Static Website Hosting

Projeto de hospedagem de site estático utilizando **Amazon S3**.

## Preview

![Preview do site](preview.png)

## Live Demo

http://raphaely-s3-static-site.s3-website.us-east-2.amazonaws.com

## Tecnologias utilizadas

* Amazon S3
* Static Website Hosting
* Bucket Policy
* HTML

## Etapas do projeto

1. Criação de bucket no Amazon S3
2. Upload de arquivo HTML
3. Ativação do Static Website Hosting
4. Configuração de Bucket Policy para acesso público
5. Publicação do site na internet
